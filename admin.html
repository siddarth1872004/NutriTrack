System notes

Authentication accounts are stored in .nutritrack/auth.sqlite3. This is a local-only admin console, bound to your computer. User nutrition snapshots sync from each user's browser while the tracker is open. Assigned dietitians can review the snapshot and leave recommendations; users can read those notes in their tracker. This is a local demo, not a clinical record system. Do not expose the local server to a network.
